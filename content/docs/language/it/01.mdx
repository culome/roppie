不定冠词 - un, una
阳性
uno : S+辅音, Z, PS, GN开头的单数阳性名词   uno studente, uno zaino
un : 其他单数阳性名词     un lavoro, un amore

阴性
un' : 元音开头 un'isola un'italiana
una : 其他单数阴性名词 una casa una chiave


un nuovo inizio  一个新的开始

- 不定冠词的变化是根据后面的词的开头来变化的, 无论后面的词是
名词还是形容词。
- 定冠词也是如此, 根据后面单词开头字母来变化。

例：il nuovo inizio
il nuovo corso
il nuovo lavoro
la nuova casa
il nuovo amore

直陈式现在时 il presente indicativo
： 什么是直陈式现在时？
用于描述现在发生的事情或者客观的事实。
