### 名词复数：词尾变化口诀

| 单数词尾 | 复数词尾 | 例（单数 → 复数） |
|----------|----------|--------------------|
| -o | -i | gatto → gatti（猫） |
| -a | -e | casa → case（房子） |
| -e | -i | chiave → chiavi（钥匙） |

> 口诀：**o 变 i，a 变 e，e 也变 i**。

**语法放大镜（课本第 4 页）**

| 单数 | 性 | 复数 |
|------|----|------|
| finestra | 阴 (s.f.) | finestre（窗户） |
| libreria | 阴 (s.f.) | librerie（书店） |
| pesce | 阳 (s.m.) | pesci（鱼） |
| notte | 阴 (s.f.) | notti（夜晚） |
| albero | 阳 (s.m.) | alberi（树） |
| treno | 阳 (s.m.) | treni（火车） |

### 形容词的阴阳性变化

形容词一般放在**名词后面**，并随名词的性数变化：

- 修饰阳性名词时以 **-o** 结尾
- 修饰阴性名词时以 **-a** 结尾

| 阳性 | 阴性 |
|------|------|
| gelato italiano（意大利冰激凌） | casa italiana（意大利房子） |
| pesce buono（好吃的鱼） | notte serena（安静的夜晚） |

> 试一下：buono（好吃的）、sereno（安静的）

### 形容词的单复数

形容词的复数变化与名词一致：**-o → -i**，**-a → -e**。

**练习（课本第 4 页第 5 题）**

| 单数短语 | 复数短语 |
|----------|----------|
| ragazzo alto（高个子男生） | ragazzi alti |
| macchina rossa（红色的汽车） | macchine rosse |
| finestra aperta（开着的窗子） | finestre aperte |
| casa nuova（新房子） | case nuove |

### 不定冠词 un / una

**阳性**

| 冠词 | 用于 | 例 |
|------|------|----|
| uno | s + 辅音、z、ps、gn 开头的单数阳性名词 | uno studente、uno zaino |
| un | 其他单数阳性名词 | un lavoro、un amore |

**阴性**

| 冠词 | 用于 | 例 |
|------|------|----|
| un' | 元音开头的单数阴性名词 | un'isola、un'italiana |
| una | 其他单数阴性名词 | una casa、una chiave |

> un nuovo inizio —— 一个新的开始

- 不定冠词的形式由**紧跟其后的那个词的开头字母**决定，无论后面是名词还是形容词。
- 定冠词也是如此，根据后面单词的开头字母变化。

例：

```
il nuovo inizio    il nuovo corso
il nuovo lavoro    il nuovo amore
la nuova casa
```

### 直陈式现在时 il presente indicativo

**什么是直陈式现在时？** 用于描述现在发生的事情或客观事实。

**动词变位：-are 第一组动词（以 lavorare「工作」为例）**

| 人称 | 变位 |
|------|------|
| io（我） | lavoro |
| tu（你） | lavori |
| lui / lei（他 / 她） | lavora |
| noi（我们） | lavoriamo |
| voi（你们） | lavorate |
| loro（他们） | lavorano |
