### 不定冠词 un / una

**阳性**

| 冠词 | 用于 | 例 |
|------|------|----|
| uno | s + 辅音、z、ps、gn 开头的单数阳性名词 | uno studente、uno zaino |
| un | 其他单数阳性名词 | un lavoro、un amore |

**阴性**

| 冠词 | 用于 | 例 |
|------|------|----|
| un' | 元音开头的单数阴性名词 | un'isola、un'italiana |
| una | 其他单数阴性名词 | una casa、una chiave |

> un nuovo inizio —— 一个新的开始

- 不定冠词的形式由**紧跟其后的那个词的开头字母**决定，无论后面是名词还是形容词。
- 定冠词也是如此，根据后面单词的开头字母变化。

例：

```
il nuovo inizio    il nuovo corso
il nuovo lavoro    il nuovo amore
la nuova casa
```

### 直陈式现在时 il presente indicativo

**什么是直陈式现在时？** 用于描述现在发生的事情或客观事实。

**动词变位：-are 第一组动词（以 lavorare「工作」为例）**

| 人称 | 变位 |
|------|------|
| io（我） | lavoro |
| tu（你） | lavori |
| lui / lei（他 / 她） | lavora |
| noi（我们） | lavoriamo |
| voi（你们） | lavorate |
| loro（他们） | lavorano |
