## 不规则动词 essere 的变位（课本 P5）

| 人称 | 变位 |
|------|------|
| io（我） | sono |
| tu（你） | sei |
| lui / lei（他 / 她） | è |
| noi（我们） | siamo |
| voi（你们） | siete |
| loro（他们） | sono |

**造句**

- 我是 Simona。 → Io sono Simona. → Sono Simona.（意大利语可省略主语）
- Sono italiano. 我是意大利人 ／ Sono italiani. 他们是意大利人
- 你是 Sandra。 → Tu sei Sandra. → Sei Sandra.
- 她是 Maria 吗？ → Lei è Maria? → È Maria? → È Maria lei?

> 一般疑问句不需要倒装，只需将陈述句的语调上扬即可。主语位置比较随意，常出现在句末（以后会继续碰到）；出现主语是为了强调。

## 名词的阴阳性与单复数

名词的阴阳性：-o → s.m.，-a → s.f.，-e → s.m./s.f.

| 名词 | 中文 | 性 | 复数 |
|------|------|----|------|
| treno | 火车 | s.m. | treni |
| finestra | 窗户 | s.f. | finestre |
| giornale | 报纸 | s.m. | giornali |
| chiave | 钥匙 | s.f. | chiavi |

> 名词的单复数：-o → -i，-a → -e，-e → -i

## 词汇

| 单词 | 翻译 |
|------|------|
| **buongiorno** | 早上好，你好（正式） |
| **questi** | 这些 |
| questo | 这个（阳性单数） |
| questa | 这个（阴性单数） |
| queste | 这些（阴性复数） |
| **quello / a** | 那个 |
| **quelli / e** | 那些 |
| **e** | 和 |
| **americano** | 美国人，美国的 |
| **piacere** | 幸会，很高兴认识你 |
| **spagnola** | 西班牙人，西班牙的（问女生）→ spagnolo（问男生） |
| **sì** | 是的 ↔ no：不是 |
| **e tu?** | 你呢 |

> 指示词：questo/questi 为阳性（单数/复数），questa/queste 为阴性（单数/复数）；quello 系列同理表示"那"。
> 国籍形容词需与人物性别一致：问女生用 spagnola，问男生用 spagnolo。

例：这个是 Simona. → Questa è Simona.

## 造句

### 一、对话

| 中文 | Italiano |
|------|----------|
| 你好，我是 Simona。 | Buongiorno, sono Simona. |
| 很高兴认识你，我是 Aldo，你是中国人吗？ | Piacere, sono Aldo. Sei cinese? |
| 是的，我是中国人。你呢？ | Sì, sono cinese. E tu? |
| 我是意大利人。 | Sono italiano. |

**词汇变化：** cinese → cinesi（复数）

### 二、介绍他人

| 中文 | Italiano |
|------|----------|
| 这两位是 Simona 和 Sandra，她们是意大利人。 | Queste sono Simona e Sandra, sono italiane. |
| 这两位是 Aldo 和 Matteo，他们是中国人。 | Questi sono Aldo e Matteo, sono cinesi. |
| 这几位是 Simona、Aldo 和 Sandra，他们是美国人。 | Questi sono Simona, Aldo e Sandra, sono americani. |

**※ 语法要点：几个人里只要有一个是男的，就要用阳性。**

- 全是女性 → 阴性复数：**queste** … **italiane**
- 含有男性 → 阳性复数：**questi** … **cinesi / americani**

| **Brasile** | brasiliano | 巴西 |
| **Marocco** | marocchino | 摩洛哥 |
| **Argentina** | argentino | 阿根廷 |
| **Francia** | francese | 法国 |
| **Germania** | tedesco | 德国 |

意大利语国籍形容词分两类，要随人物的性别和数量变化：

### 第一类：以 -o 结尾（有 4 种形式）

| | 阳性 | 阴性 |
|------|------|------|
| **单数** | italiano | italiana |
| **复数** | italiani | italiane |

属于这一类的有：italiano、americano、spagnolo、australiano、brasiliano、marocchino、argentino、tedesco

例：
- 一个意大利男生 → italian**o**
- 一个意大利女生 → italian**a**
- 几个意大利男生 / 男女混合 → italian**i**
- 几个意大利女生 → italian**e**

### 第二类：以 -e 结尾（只有 2 种形式，不分阴阳性）

| | 阳性 / 阴性通用 |
|------|------|
| **单数** | cinese |
| **复数** | cinesi |

属于这一类的有：cinese、francese

例：
- 一个中国男生 / 女生 → cinese
- 几个中国人 → cinesi

**※ 记忆要点：** -o 结尾的变 o/a/i/e 四形；-e 结尾的只变单复数（cinese → cinesi，francese → francesi）。几个人里只要有一个男的，就用阳性复数。

## 定冠词 (Articoli Determinativi)

### 一、定冠词表

| 性 | 单数 | 复数 | 使用条件 |
|------|------|------|----------|
| **阳性** | l' | gli | 元音开头的单词 |
| **阳性** | lo | gli | s+辅音、z、gn、ps 等开头的单词 |
| **阳性** | il | i | 其他辅音开头的单词 |
| **阴性** | l' | le | 元音开头的单词 |
| **阴性** | la | le | 其他（辅音开头）的单词 |

### 二、选择规则

**先判断阴阳性，再看单词开头的字母：**

阳性：
- 元音开头 → 单数 **l'** ，复数 **gli**
- s+辅音 / z / gn / ps 开头 → 单数 **lo** ，复数 **gli**
- 其他辅音开头 → 单数 **il** ，复数 **i**

阴性：
- 元音开头 → 单数 **l'** ，复数 **le**
- 其他辅音开头 → 单数 **la** ，复数 **le**

### 三、练习：填写定冠词

| 定冠词 | 单词 | 中文 | 说明 |
|--------|------|------|------|
| **gli** | stivali | 靴子 | 阳性复数，元音 i 开头 |
| **lo** | zaino | 背包 | 阳性单数，z 开头 |
| **la** | zia | 阿姨、婶婶、舅婆等 | 阴性单数，辅音开头 |
| **il** | panino | 夹心面包 | 阳性单数，普通辅音开头 |
| **gli** | aerei | 飞机 | 阳性复数，元音 a 开头 |
| **l'** | opera | 歌剧 | 阴性单数，元音 o 开头 |
| **i** | numeri | 数字 | 阳性复数，普通辅音开头 |
| **il** | museo | 博物馆 | 阳性单数，普通辅音开头 |

**※ 记忆要点：** gli 用于阳性复数（元音 + s辅音/z/gn/ps 开头）；i 用于阳性复数（其他辅音）；le 是阴性复数的统一形式，不分开头字母。
