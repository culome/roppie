### 情景交际（一）

> **A:** Frau Müller, was ist das auf Deutsch?
> **B:** Das ist ein Buch.
> **A:** Entschuldigung, wie bitte?
> **B:** Ein Buch. Das ist ein Buch.
> **A:** Können Sie das bitte buchstabieren?
> **B:** Ja, natürlich. B-U-C-H, Buch.
> **A:** Was bedeutet das?
> **B:** Auf Englisch sagt man "book".

### 情景交际（二）

> **A:** Marina, wie heißt das auf Deutsch?
> **B:** Ich weiß nicht.
> **C:** Das ist eine Tasche.
> **B:** Können Sie das bitte wiederholen?
> **C:** Das ist eine Tasche.
> **A:** Können Sie das bitte anschreiben?
> **C:** Ja, klar.
> **A:** Danke schön.
> **C:** Bitte schön.
> **D:** Tschüss.
> **C:** Tschüss.

**常用请求句式**

- Können Sie das bitte **buchstabieren**? 请您拼读一下好吗？
- Können Sie das bitte **wiederholen**? 请您重复一下好吗？
- Können Sie das bitte **anschreiben**? 请您写下来好吗？

## 12 重点语法（一）：定冠词 & 不定冠词

<video controls preload="metadata" width="100%">
  <source src="https://r2.roppie.com/de/A1-L2-S12.mp4" type="video/mp4" />
</video>

### 名词的三性

德语名词分**阳性、中性、阴性**三种性：

| 阳性 (der) | 中性 (das) | 阴性 (die) |
|------------|------------|------------|
| der Mann（男人、丈夫） | — | die Frau（女人、妻子） |
| der Lehrer（男老师） | — | die Lehrerin（女老师） |
| der Mond（月亮） | — | die Sonne（太阳） |

### 定冠词

定冠词用于特指，相当于英语的 *the*：

| | 阳性 Maskulinum | 中性 Neutrum | 阴性 Femininum | 复数 Plural |
|---|---|---|---|---|
| 定冠词 | der | das | die | die |

例：

| 单数 | 复数 |
|------|------|
| das Buch | die Bücher |
| der Lehrer | die Lehrer |
| die Lehrerin | die Lehrerinnen |

### 名词复数的常见变化

| 复数词尾 | 例（单数 → 复数） |
|----------|--------------------|
| -s | der CD-Player → die CD-Player（实为不变） |
| -n | die Tasche → die Taschen |
| -s | der Kuli → die Kulis |
| -e | der Tisch → die Tische |
| -(n)en | die Lehrerin → die Lehrerinnen |
| -̈e（变音 + e） | der Stuhl → die Stühle |
| -̈er（变音 + er） | das Buch → die Bücher |

例句：

> Das ist ein Auto.（这是一辆汽车。）
> Das Auto ist sehr teuer.（这辆车很贵。）

### 否定词 kein

**kein** 用于否定带不定冠词或无冠词的名词：

> Das ist ein Buch.（这是一本书。）
> Das ist kein Buch.（这不是一本书。）

不定冠词与否定冠词对照：

| 性 / 数 | 定冠词 | 不定冠词 | 否定冠词 |
|---------|--------|----------|----------|
| 阳性 | der | ein | kein |
| 中性 | das | ein | kein |
| 阴性 | die | eine | keine |
| 复数 | die | —（无） | keine |

### 强变化动词变位

部分动词在**第二、三人称单数**时词干元音需要变音或换音（e → i/ie，a → ä 等）：

| 人称 | essen（吃） | nehmen（拿） | sprechen（说） |
|------|------------|--------------|----------------|
| ich | esse | nehme | spreche |
| du | **isst** | **nimmst** | **sprichst** |
| er / es / sie | **isst** | **nimmt** | **spricht** |
| wir | essen | nehmen | sprechen |
| ihr | esst | nehmt | sprecht |
| Sie / sie | essen | nehmen | sprechen |

> 注意：变化只发生在 **du** 和 **er/es/sie** 两个人称，其余人称按规则变位。
